Privacy Policy — nextBus

Effective Date: November 17, 2026

1. Data We Process

nextBus provides real-time public transit arrival estimates in Israel via Google Connected Apps and the Model Context Protocol (MCP). When you request bus status, your query transmits your requested line number and approximate GPS coordinates solely to locate the nearest public transit stop.

2. Ephemeral Caching & No Personal Tracking

GPS coordinates passed in get_live_bus_status are used only during the active request for geospatial lookup against PostGIS stop tables and are never persisted to user profiles, sold, or shared for advertising. Live bus telemetry is cached transiently in Redis for up to 60 seconds.

3. Third-Party Data Sources

Real-time vehicle telemetry is sourced asynchronously from the Open Bus Stride API (Hasadna / MOT Israel) by background workers.

4. Contact

For privacy inquiries regarding the nextBus service, contact the project maintainer via the verified service domain.
